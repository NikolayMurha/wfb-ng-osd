# WFB-NG OSD

GStreamer/OpenGL OSD-компонент для FPV-відео WFB-NG.

Документація зберігається лише в центральному репозиторії:
[WFB-NG OSD](https://github.com/LegitForceLab/lte-docs/tree/main/projects/wfb-ng-osd).

## Пінг маршруту в OSD

Плеєр отримує пінг через той самий UDP-порт, що й MAVLink-телеметрію
відповідного відеопотоку. Окремий порт для пінгів не потрібен.
Вимірювання виконує зовнішній пінгер; плеєр лише показує результат.

Формат для інтеграції: MAVLink `NAMED_VALUE_INT`, `name="PING"`,
`value=0..60000` у мілісекундах або `value=-1`, якщо відповіді немає.
`time_boot_ms` — час роботи відправника; свіжість визначається локально
за часом отримання. Прив'язка до маршруту визначається портом приймача,
без окремого ідентифікатора каналу чи фільтра за системою автопілота.
Це не стандартне повідомлення MAVLink `PING`.

Після першого коректного повідомлення OSD показує поточний пінг і до двох
попередніх значень. За відсутності відповіді або нових даних понад 5 секунд
поточне значення змінюється на `---`, індикатор стає червоним.
Повідомлення пінгера не підтримують статус живої телеметрії автопілота.
Приховати індикатор можна через `-D ping`.
